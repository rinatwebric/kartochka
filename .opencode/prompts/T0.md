# Задача T0 — каркас проекта

Ты работаешь в папке `C:\Users\user\Desktop\kartochka`. Это проект КАРТОЧКА (веб-приложение,
которое делает карточку товара для маркетплейса и проверяет её по регламенту площадки).

## Что прочитать перед началом

1. `AGENTS.md` — правила работы (обязательны).
2. `MASTER.md` — разделы 3 (стек), 4 (структура папок), 5 (архитектура).

## Что сделать

Инициализировать Next.js 15 проект ПРЯМО В ЭТОЙ ПАПКЕ, не удаляя и не перезаписывая существующие
`MASTER.md`, `AGENTS.md`, `rules/`, `docs/`, `.opencode/`.

`create-next-app` в непустой папке не использовать — создай файлы сам, вручную, по списку ниже.
Пакетный менеджер: `pnpm` (установлен, версия 12.x). Node v24. Терминал — Windows (cmd/powershell),
пути Windows.
