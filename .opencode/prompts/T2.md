# T2 — клиент моделей Meta + MOCK

Сначала открой https://dev.meta.ai/docs и сверь имена полей и эндпоинты. Если документация
расходится с MASTER.md — права документация, расхождение запиши в docs/DECISIONS.md.
Выдумывать поля API запрещено.

Сделать:
1. lib/env.ts — zod-схема переменных: MODEL_API_KEY, META_BASE_URL (default https://api.meta.ai/v1),
   MOCK (default "1"). Экспорт типизированного объекта, при отсутствии ключа MOCK принудительно 1.
2. lib/models/meta.ts — единый клиент:
   - один fetch с AbortController-таймаутом (60 с);
   - 2 ретрая с экспоненциальной паузой на 429/5xx; на 4xx не ретраить;
   - лог одной строкой: [model] name=... ms=... credits=... status=...;
   - счётчик кредитов (простая оценка по числу вызовов, множители в константах);
   - типизированная ошибка ModelError с человеческим сообщением.
3. lib/models/{sam,image,spark,glimmer}.ts — тонкие обёртки: sam (маска по картинке и промпту),
   image (правка/генерация по маске), spark (текст/vision-вопрос), glimmer (вердикт same=true/false).
   Ответы моделей бывают base64 и URL — поддерживай оба, zod-валидация ответа.
4. lib/mock/provider.ts + fixtures.ts — при MOCK=1 или без ключа возвращать детерминированные
   фикстуры (маска, картинка, текст, вердикт), задержка 300-800 мс, ошибок не бросает.
5. Минимальный скрипт-проверка (без тестового фреймворка): scripts/check-models.ts, который
   в mock-режиме прогоняет все четыре обёртки и печатает что вернулось. Запуск: pnpm tsx
   scripts/check-models.ts (добавь tsx в devDependencies, это разрешено записать в DECISIONS).

Проверка: pnpm build; pnpm tsx scripts/check-models.ts -> все четыре обёртки отвечают, в логе
видны ms и credits.
