# T4 — identity gate и петля ретраев

Сделать:
1. lib/utils/phash.ts — pHash через DCT 32x32 -> 8x8, hamming-расстояние, тест на одинаковых
   и разных картинках.
2. lib/utils/hsv.ts — гистограмма HSV, корреляция двух гистограмм.
3. lib/utils/ssim.ts — SSIM по области маски (упрощённый оконный вариант допустим, но формула
   должна быть настоящей, не «похожесть на глаз»).
4. lib/pipeline/identity.ts — формула из MASTER.md раздел 8:
   identity = 0.35*(1-hamming) + 0.25*HSV + 0.25*SSIM + 0.15*glimmer, порог 0.90,
   и объяснение вклада каждого сигнала (объект с полями).
5. Петля в runner.ts: если identity < 0.90 — перегенерировать главный кадр с усиленным промптом,
   максимум 2 ретрая, каждый раз пересчитывать identity и писать attempt в состояние.
   glimmer спрашивать 3 раза, брать большинство.

Проверка: scripts/check-identity.ts — берёт тестовое фото, считает identity на «том же» кадре
(должно быть >= 0.90) и на специально подменённом похожим (должно быть < 0.90); печатает оба числа
и разбивку по сигналам. Петля проверяется тем, что при подмене в состоянии видно 2 ретрая.
