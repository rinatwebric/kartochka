# T5 — движок регламента, чек-лист, fix hints

Сделать lib/pipeline/rules.ts:
1. Читает rules/<marketplace>.json (wb, ozon, amazon). В коде правил НЕТ, только исполнители типов.
2. Поддержать типы проверок: pixels_white, aspect, min_size, fill, not_cropped — считаются кодом;
   no_text_on_main, no_watermark, single_object — через lib/models/spark.ts (vision), с обязательным
   bbox и reason в ответе, при отсутствии уверенности — false (лучше честный провал).
3. Каждый пункт результата: id, label, ok, measured (человеческая строка, например
   «заполнение 71%», «фон 96% белый»), weight, fix (что сделать руками), reason (почему не прошло).
4. compliance = сумма весов пройденных / сумма всех весов; score = round(compliance*100).
5. Добавление площадки = новый JSON-файл, без правки кода. Это проверить: создай в проверке
   временный rules/test.json и прогони без изменения кода.

Проверка: scripts/check-rules.ts — прогоняет фикстуры метрик на все три площадки, включая кейс,
когда фото валидно для Ozon, но не для Amazon; печатает таблицу «пункт / замер / ок-не ок» и итог.
